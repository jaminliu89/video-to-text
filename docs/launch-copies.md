## 2. 掘金 / 知乎（技术向 + 实现思路）

### 标题
开源一个基于 NiceGUI 的视频转文字工具——把课程视频变成可检索的结构化笔记

### 正文

**背景**

作为一个买课狂魔，我一直有个痛点：买了一堆课程，存了一堆讲座视频，想找个知识点的时候得来回拖进度条，效率极低。

市面上的工具要么贵（0.5元/分钟谁用得起），要么只能出纯文字没有结构，要么要把视频传到第三方服务器（敏感内容不敢传）。

所以自己写了一个。

**项目地址**：https://github.com/jaminliu89/video-to-text

**核心功能**

1. **三种转写引擎，按需切换**
   - 豆包视频理解 — 基于火山方舟，能理解动态画面和人物关系，质量最高
   - 关键帧 + VLM — 抽关键帧用视觉模型分析，便宜，适合 PPT 类视频
   - 本地 whisper.cpp — 完全本地跑，不花一分钱，适合敏感内容

2. **两种输出模式**
   - 逐字稿模式：SRT / TXT / Markdown 带时间戳
   - 深度拆解模式：摘要 + 章节 + 金句 + 行动项 + 原文引用

3. **GUI + CLI 双模式**
   - 日常用 GUI（基于 NiceGUI，Parchment 浅色风格）
   - 自动化用 CLI，支持批量处理文件夹

4. **Obsidian 原生导出**
   - 直接写入 Vault，跟笔记体系无缝衔接

5. **缓存机制**
   - 同一个视频不重复处理，省钱省时间

**技术栈**

- 前端：NiceGUI 3.x + Quasar + 自定义 Parchment 主题
- 后端：纯 Python，OpenAI SDK 兼容多平台
- 本地模型：whisper.cpp
- 视频处理：ffmpeg

**为什么选 NiceGUI**

之前也考虑过 Electron + React，但太重了。
NiceGUI 的好处是：纯 Python，写后端的同时就把前端写了，自带组件库，打包也简单（PyInstaller 一条命令）。
对于个人工具来说，开发速度比什么都重要。

**踩过的一些坑**

1. NiceGUI 的 Material Icons 不是内置的，要自己加载 CDN + CSS 豁免
2. `ui.state()` 有快照语义坑，异步函数里读不到最新值，改用模块级全局变量
3. Quasar 浅色模式下 uploader header 是黑底黑字，必须手动覆盖
4. 打包 PyInstaller 要加 `--collect-data nicegui`，不然静态资源找不到

**后续计划**

- [ ] 说话人分离（diarization）

- [ ] 插件系统（自定义输出模板）

## 3. V2EX（极客范 + 简洁）

### 标题
[分享] VideoToText — 本地优先的视频转结构化文字工具

### 正文

做了一个视频转文字的工具，自己用了一段时间觉得不错，开源分享一下。

**地址**：https://github.com/jaminliu89/video-to-text

**能做什么**

- 三种引擎：豆包视频理解 / 关键帧+VLM / 本地 whisper.cpp
- 两种模式：逐字稿 / 深度拆解（摘要+章节+金句+行动项）
- GUI（NiceGUI）+ CLI 双模式
- 批量处理文件夹
- Obsidian 导出
- 本地缓存，不重复处理

**为什么又造一个轮子**

- 现有工具大多只能出纯逐字稿，没有结构化输出
- 很多工具是 SaaS 模式，视频要传上去，敏感内容不敢用
- 想找一个能直接写进 Obsidian 的，没找到合适的
- 正好练手 NiceGUI

**技术栈**：Python + NiceGUI + ffmpeg + OpenAI 兼容 API

MIT 协议，随便用。
有 bug 提 issue，PR 欢迎。
